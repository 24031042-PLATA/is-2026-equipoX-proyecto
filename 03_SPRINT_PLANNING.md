# Planificación del Sprint 1.

**Proyecto:** DataDoc.  
**Sprint:** 1.  
**Duración:** 2 semanas.

## 1. Objetivo del Sprint.
El objetivo de este Sprint es desarrollar las primeras funciones de DataDoc para que el usuario pueda cargar archivos CSV y Excel, revisar su contenido y obtener un análisis básico.

Al terminar, el sistema deberá permitir cargar un archivo, procesar sus datos y mostrar información general sobre ellos.

## 3. Actividades del Sprint.
Para cumplir con el objetivo, el equipo realizará las siguientes actividades:

1. Preparar los programas necesarios para trabajar.
2. Instalar las librerías que utilizará el proyecto.
3. Crear la función para cargar archivos CSV y Excel.
4. Programar la revisión y el procesamiento de los datos.
5. Obtener estadísticas básicas de los archivos.
6. Detectar datos faltantes y registros repetidos.
7. Probar cada función para comprobar que trabaje correctamente.
8. Unir las funciones desarrolladas en el sistema.


## 4. Reglas para considerar una tarea terminada.
### Antes de comenzar.
Una tarea estará lista para comenzar cuando:

- Se entienda qué se debe hacer.
- Tenga claros los resultados que se esperan.
- Cuente con una estimación de trabajo.
- Se conozcan las herramientas necesarias.
- El equipo esté de acuerdo con la tarea.

### Al terminar.
Una tarea se considerará terminada cuando:

- La función esté programada.
- Cumpla con lo que se pidió.
- Se haya probado y funcione correctamente.
- No tenga errores que impidan utilizarla.
- Otro integrante haya revisado el código.
- Los cambios estén guardados en Git.

## 7. Posibles problemas durante el Sprint

Durante el desarrollo podrían presentarse algunos problemas:

- Archivos que no sean compatibles con el sistema.
- Archivos demasiado grandes para la computadora.
- Columnas con datos diferentes o desordenados.
- Errores al unir las funciones programadas por el equipo.
- Retrasos al terminar alguna actividad.

Para reducir estos problemas, será importante realizar pruebas y revisar constantemente los avances.

## 8. Resultado esperado del Sprint

Al terminar el primer Sprint, DataDoc deberá permitir cargar archivos CSV y Excel, revisar su contenido y mostrar información básica.

También deberá poder generar estadísticas e identificar datos faltantes y registros repetidos.

Con estas funciones se tendrá la primera parte del sistema lista para continuar con el siguiente Sprint, donde se trabajará en los resúmenes, la visualización de resultados y la limpieza opcional de los datos.
