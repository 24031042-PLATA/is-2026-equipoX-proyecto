## 1. Descripción del proyecto.

DataDoc es una plataforma de software enfocada en el procesamiento, estandarización y análisis de diferentes tipos de datasets.

El sistema tiene como propósito facilitar la comprensión de los conjuntos de datos mediante la generación de resúmenes, estadísticas e identificación de información relevante.

También permite realizar operaciones de limpieza y estandarización de manera opcional, para que el usuario tenga el control sobre las modificaciones que quiere aplicar a sus datos.

## 2. Objetivo general.

Desarrollar una plataforma que permita cargar, procesar y analizar diferentes conjuntos de datos, proporcionando información útil para facilitar su interpretación y apoyar la toma de decisiones.

## 3. Funciones principales.
- Cargar archivos CSV y Excel.
- Procesamiento y exploración de datasets.
- Identificación de filas, columnas y tipos de datos.
- Generación de estadísticas descriptivas.
- Detección de valores faltantes.
- Detección de registros duplicados.
- Generación de resúmenes del contenido.
- Identificación de información potencialmente relevante.
- Limpieza y estandarización opcional.
- Visualización de resultados del análisis.

## 4. Alcance del proyecto.

La primera versión de DataDoc estará enfocada en la carga, procesamiento y análisis de archivos CSV y Excel.

El sistema permitirá conocer las características principales de los datasets y detectar posibles problemas de calidad.

La limpieza y estandarización serán funcionalidades opcionales. El usuario podrá decidir si desea aplicar modificaciones o conservar los datos originales.

El proyecto no contempla inicialmente el entrenamiento de modelos de inteligencia artificial ni la generación de predicciones.
