## PROCEDIMIENTOS
**Formato de Commits:**  Se utilizarán convenciones como feat:, fix:, docs: y style:.
**Estrategia de ramas (Branching):** No se realizarpan cambios directamente en la rama main. Cada cambio se realizarpa mediante una rama feature/* y posteriormente se integrará mediante un Pull Request.
**Política de Code Review:** Todo Pull Request deberá ser revisado y aprobado por al menos un integrante del equipo antes de realizar el Merge a main.
